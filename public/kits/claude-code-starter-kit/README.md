# Claude Code Starter Kit
From RGV Performance Marketing · rgvperformancemarketing.com

Thanks for grabbing the kit. Everything here is plain text, so it works with
Claude Code, Codex, and any other AI coding agent.

## What's inside

| File | What it's for |
|---|---|
| `CLAUDE.md` | The instructions file Claude Code reads at the start of every session. Fill in the blanks, drop it in your project folder. |
| `AGENTS.md` | The same idea for Codex, which reads AGENTS.md. |
| `project-spec-template.md` | A one-page spec an AI agent can build from. Write this before you ask for code. |
| `build-templates/` | Three ready-to-use specs: a lead-capture landing page, a quote calculator, and a weekly report from a spreadsheet. |
| `claude-code-cheat-sheet.md` | The commands and habits you'll use every day. |

## How to use it (15 minutes)

1. Make a new, empty folder for your project.
2. Copy `CLAUDE.md` into it and fill in the blanks. (Using Codex? Copy `AGENTS.md` instead, or both.)
3. Pick one of the build templates, or fill in `project-spec-template.md` for your own idea.
4. Open a terminal in that folder, start Claude Code (`claude`) or Codex (`codex`), and paste in the spec.
5. Review what it builds, ask for changes in plain English, and repeat.
